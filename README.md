# Profiling

Цель - профилирование Linux / FreeBSD стека на одних и тех же задачах с целью выявления слабых мест обоих.

## Warning

Warning! Не запускайте скрипты на системе которая не предназначена для тестов, поскольку скрипты могут модифицировать 
настройки и софт если что-то до этого было конфигурировано. Каждый запуск теста - предполагается что выполняется на чистом хосте.

## Usage

каждая лаба обнуляет-генерит свой стенд-конфиги через labX-setup.sh, 
цикл тестов - labX-bench анализ логов: ./parselog output/<platform>-X.log


## Лабы

Лаба 1 - HTTP RPS с nginx по loopback, одно ядро на каждый процесс
```
./lab1-setup			# подготовка окружения
./lab1-bench [ -q -d 30 -c 1 ]	# запуск теста
				# -q - подавить лишний вывод, а если идет - то в stderr
				# -d <время работы теста, в сек, default: 60
				# -c сколько ядер/потоков задействовать, default: 0  (все)
				#  можно указывать range или перечислять, можно комбинировать:
				# -c "1-3"
				# -c "1,4,8"
				# -c "1-4,8,16"
```
